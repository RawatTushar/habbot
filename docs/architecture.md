# HabotConnect Architecture

HabotConnect is organized as a small DevOps repository with four concerns:

```text
Terraform infrastructure
        |
        v
Deployment environment <- GitHub Actions security gate
        |
        v
Django API serializer <- student onboarding Excel data
```

- `terraform/` defines the deployment configuration and provider versions.
- `.github/workflows/security-gate.yml` runs repository security checks on pushes and pull requests.
- `django/serializers.py` defines the API-facing student onboarding payload.
- `schema/student_onboarding.xlsx` is the source onboarding workbook.

The Excel workbook is supplied as a project asset and is not generated by Terraform.
